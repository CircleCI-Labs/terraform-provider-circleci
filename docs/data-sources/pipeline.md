# circleci_pipeline (Data Source)

~> **Deprecated: this type name has been renamed to
[`circleci_pipeline_definition`](pipeline_definition).** It reads a pipeline
*definition* — where to find configuration and where to check out code — not a
pipeline run, and the name `circleci_pipeline` obscured that. Both names are served
by the same implementation and read exactly the same data.

`circleci_pipeline` still works. Using it produces a deprecation warning, not an
error. It will be removed in the next major release.

## Migrating

Data sources hold no state, so there is nothing to migrate: change the type name in
your configuration, and update references to it elsewhere
(`data.circleci_pipeline.example` becomes
`data.circleci_pipeline_definition.example`).

```terraform
data "circleci_pipeline_definition" "example" {
  # ... unchanged arguments ...
}
```

See [Renaming pipeline resources and data sources](../guides/renaming-pipeline-types)
for the rest of the rename.

For everything else — arguments, availability, examples — see
[`circleci_pipeline_definition`](pipeline_definition).
