# circleci_contexts (Data Source)

Fetches every CircleCI context in an organization, including contexts created
outside Terraform. Pagination is followed internally, so the result covers every
context rather than a single page. Use [`circleci_context`](context) to fetch one
context by id.

## Availability

| | |
| --- | --- |
| **CircleCI Cloud** | Yes |
| **CircleCI Server** | Yes. Contexts are a first-class CircleCI Server feature with the same v2 surface. **Reasoned rather than measured**: no CircleCI Server installation has been available to test against, so this is derived from which routes a Server installation exposes. See the CircleCI Server note on the provider index page. |
| **API** | `GET /api/v2/context` |
| **Organization type** | Any. |
| **Token** | Any valid API token with read access to the organization. |

-> **Values are a separate data source** This data source reports the contexts
themselves, not their environment variables. Use
[`circleci_context_environment_variable`](./context_environment_variable) to read
one variable — the API masks its value in any case.

## Example Usage

```terraform
# Lists every context in the organization, following pagination internally.
# Available on both CircleCI Cloud and CircleCI Server.
data "circleci_contexts" "all" {
  org_id = "00000000-0000-0000-0000-000000000000"
}

output "circleci_context_names" {
  value = [for context in data.circleci_contexts.all.contexts : context.name]
}

# The API addresses contexts by id, so look an id up by name when needed.
output "circleci_deploy_context_id" {
  value = one([
    for context in data.circleci_contexts.all.contexts : context.id
    if context.name == "deploy"
  ])
}
```

### Nested Schema for `contexts`

Read-Only:

- `name` (String) Name of the context.

## Notes

* `contexts` is always a list, empty when the organization has no contexts, so
  configurations can iterate over it unconditionally.
* `created_at` is recorded exactly as the API reported it.
* Only organization-owned contexts are listed. The API documents an account owner
  type but rejects it, so this data source always asks for the organization.
