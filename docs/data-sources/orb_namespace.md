# circleci_orb_namespace (Data Source)

Looks up a CircleCI orb registry namespace by name or by id.

This is the usual way to get the `namespace_id` that `circleci_orb` needs for a namespace this configuration does not manage. It is also how to find the namespace name behind a self-hosted runner resource class, which is always `<namespace>/<class>`.

Set exactly one of `id` and `name`.

## Availability

| | |
| --- | --- |
| **CircleCI Cloud** | Yes |
| **CircleCI Server** | No — served by the CircleCI v3 API, which a Server installation does not route to its public API service. Using this with `deployment = "server"` reports an explicit error at plan time rather than the confusing HTTP 404 the request would otherwise produce. |
| **API** | `GET /api/v3/namespaces/{id}`, or `GET /api/v3/namespaces` filtered by name |
| **Organization type** | Any. |
| **Token** | Any valid API token. |

## Example Usage

```terraform
# Look up a namespace this configuration does not manage, to get the
# namespace_id a circleci_orb needs.
data "circleci_orb_namespace" "example" {
  name = "circleci"
}

# Either key works; set exactly one.
data "circleci_orb_namespace" "by_id" {
  id = "11111111-1111-1111-1111-111111111111"
}
```
