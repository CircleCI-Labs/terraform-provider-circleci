# circleci_pipeline_run_config (Data Source)

Fetches the source and compiled configuration for a CircleCI pipeline run — genuinely useful for
asserting what a run actually compiled to, orb expansion included, rather than trusting that the
checked-in YAML alone reflects what ran.

~> **This is a point-in-time read.** A run's configuration does not change once compiled, but the run
itself might not exist yet, or might still be compiling, when this is read — `source` and `compiled` are
then empty strings. Use this data source for inspection and in `check` blocks; using it to derive a
resource attribute will cause a diff for any run whose configuration was not yet available at read time.

## Availability

| | |
| --- | --- |
| **CircleCI Cloud** | Yes |
| **CircleCI Server** | Yes — implemented directly in the same v2 API application on both deployments; see [`circleci_pipeline_run`](pipeline_run). |
| **API** | `GET /api/v2/pipeline/{id}/config` |
| **Organization type** | Any. |
| **Token** | Any valid API token with permission to view the project's builds. |

## Example Usage

```terraform
# Fetches the resolved (compiled) and original configuration for a pipeline
# run. Available on both CircleCI Cloud and CircleCI Server.
data "circleci_pipeline_run" "this" {
  project_slug = "gh/CircleCI-Public/api-preview-docs"
  number       = 25
}

data "circleci_pipeline_run_config" "this" {
  run_id = data.circleci_pipeline_run.this.id
}

# Assert the compiled config actually contains an expected orb, rather than
# trusting that the checked-in YAML alone reflects what ran.
check "orb_was_expanded" {
  assert {
    condition     = strcontains(data.circleci_pipeline_run_config.this.compiled, "circleci/node")
    error_message = "Compiled pipeline config no longer references the circleci/node orb."
  }
}
```

## Schema

### Required

- `run_id` (String) Unique identifier (UUID) of the pipeline run, as returned by [`circleci_pipeline_run`](pipeline_run).

### Read-Only

- `compiled` (String) The compiled configuration, after orb expansion. May be empty if there were errors processing the configuration.
- `compiled_setup_config` (String) The compiled setup configuration, after orb expansion. Null when the run did not use setup workflows; may be empty if there were errors processing the setup configuration.
- `setup_config` (String) The setup configuration used for setup workflows. Null when the run did not use setup workflows.
- `source` (String) The source configuration, before any config compilation. Empty when the run has no configuration (yet).
