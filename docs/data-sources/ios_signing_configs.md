# circleci_ios_signing_configs (Data Source)

Fetches every iOS signing configuration in a CircleCI organization, including configurations created outside Terraform. Pagination is followed internally, so the result covers every configuration rather than one page.

## Availability

| CircleCI Cloud | CircleCI Server |
|---|---|
| yes | **no** |

~> **Not available on CircleCI Server.** Signing configurations are served by the CircleCI v3 API, which CircleCI Server does not route to the public API service.

-> **There is no singular data source.** The API has no route to fetch one signing configuration by id (only `GET /signing/configs`, `POST /signing/configs` and `DELETE /signing/configs/{id}`), so there is nothing for a singular `circleci_ios_signing_config` data source to call. Match on `name` or `id` against this data source's result instead.

## Example Usage

```terraform
# There is no singular circleci_ios_signing_config data source: the API has no
# route to fetch one configuration by id. List and match on name instead.
data "circleci_ios_signing_configs" "all" {
  org_id = "00000000-0000-0000-0000-000000000000"
}

output "release_signing_config_id" {
  value = [
    for cfg in data.circleci_ios_signing_configs.all.configs :
    cfg.id if cfg.name == "release-signing"
  ][0]
}
```

## Security

Each provisioning profile's `.mobileprovision` content is write-only: only `file_name` is reported back, exactly like a certificate's content — see [`circleci_ios_signing_certificate`](../resources/ios_signing_certificate)'s "Security" section.
