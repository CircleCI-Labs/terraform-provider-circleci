# circleci_organization_settings (Data Source)

Fetches the organization-wide settings for a CircleCI organization.

## Availability

**CircleCI Cloud only.** These settings are served by the CircleCI v3 API, which CircleCI Server does not route to its public API service. Configuring the provider with `deployment = "server"` and using this data source reports an explicit error rather than a confusing HTTP 404.

Unlike the `circleci_organization_settings` resource, every attribute here reports the value CircleCI currently holds. A read-only view has no notion of an unmanaged toggle, so all of them are populated.

## Settings that gate other resources

| Setting | What it gates |
| --- | --- |
| `is_runner_terms_of_service_accepted` | Self-hosted runner onboarding. Runner resource classes and tokens are unavailable while this is `false`. |
| `enable_private_orbs` | Private orbs. The organization can neither publish nor reference a private orb while this is `false`. |
| `is_user_checkout_keys_disabled` | Checkout keys. When `true`, deploy keys are the only checkout credential. |
| `is_context_group_restriction_required` | Context restrictions. When `true`, every context must carry at least one restriction. |

## Example Usage

```terraform
data "circleci_organization_settings" "example" {
  org_id = "00000000-0000-0000-0000-000000000000"
}

# Runner onboarding is gated on the terms of service, so check before creating
# runner resources.
output "runners_available" {
  value = data.circleci_organization_settings.example.is_runner_terms_of_service_accepted
}

output "private_orbs_available" {
  value = data.circleci_organization_settings.example.enable_private_orbs
}
```

### Read-Only

- `enable_ai_agents` (Boolean) Whether CircleCI AI agents may run for this organization.
- `enable_ai_error_summarization` (Boolean) Whether CircleCI generates AI summaries of build and test failures.
- `enable_certified_public_orbs` (Boolean) Whether pipelines may use public orbs certified by CircleCI.
- `enable_chunk_ip_ranges` (Boolean) Whether the organization is opted into chunked IP address ranges.
- `enable_image_brownouts` (Boolean) Whether the organization is opted into scheduled brownouts of deprecated Docker images.
- `enable_minor_ai_features` (Boolean) Whether smaller AI-backed conveniences are enabled in the CircleCI web application.
- `enable_private_orbs` (Boolean) Whether the organization may publish and use private orbs. Private orbs cannot be created or referenced while this is `false`.
- `enable_resource_class_brownouts` (Boolean) Whether the organization is opted into scheduled brownouts of deprecated resource classes.
- `enable_uncertified_public_orbs` (Boolean) Whether pipelines may use public orbs that CircleCI has not certified.
- `enable_unversioned_config` (Boolean) Whether pipelines may run configuration that carries no `version` pin.
- `is_bitbucket_workspace_member_org_member` (Boolean) Whether every member of the linked Bitbucket workspace counts as a member of this CircleCI organization.
- `is_context_group_restriction_required` (Boolean) Whether every context in this organization must carry at least one group restriction.
- `is_runner_terms_of_service_accepted` (Boolean) Whether the CircleCI self-hosted runner terms of service have been accepted. Runner onboarding is gated on this: runner resource classes and tokens are unavailable while it is `false`.
- `is_running_disabled` (Boolean) Whether the organization is blocked from running pipelines.
- `is_user_checkout_keys_disabled` (Boolean) Whether user checkout keys are forbidden, leaving deploy keys as the only checkout credential.
