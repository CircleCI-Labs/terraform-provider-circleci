# circleci_deploy_environment (Data Source)

Fetches one CircleCI deploy/release environment by id. Use
[`circleci_deploy_environments`](deploy_environments) to list every environment in an organization, e.g.
to look one up by name — the API has no lookup-by-name route.

## Availability

| | |
| --- | --- |
| **CircleCI Cloud** | Yes |
| **CircleCI Server** | No — deploy/release tracking (the API) is not deployed on CircleCI Server. Using this data source with `deployment = "server"` reports an explicit error. |
| **API** | `GET /api/v2/deploy/environments/{id}` |
| **Organization type** | Any. |
| **Token** | Any valid API token. |

## Example Usage

```terraform
# Fetches one deploy/release environment by id.
# Available on CircleCI Cloud only.
data "circleci_deploy_environment" "prod" {
  id = "00000000-0000-0000-0000-000000000000"
}

output "circleci_prod_environment_labels" {
  value = data.circleci_deploy_environment.prod.labels
}
```
