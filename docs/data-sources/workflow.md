# circleci_workflow (Data Source)

Fetches one CircleCI workflow by id.

~> **This is a point-in-time read of mutable runtime state.** `status` and `stopped_at` change as the
workflow runs. Use this data source for inspection and in `check` blocks; using it to derive a resource
attribute will cause a perpetual diff.

## Availability

| | |
| --- | --- |
| **CircleCI Cloud** | Yes |
| **CircleCI Server** | Yes — implemented directly in the same v2 API application on both deployments (`the CircleCI API`); see [`circleci_pipeline_run`](pipeline_run). |
| **API** | `GET /api/v2/workflow/{id}` |
| **Organization type** | Any. |
| **Token** | Any valid API token with permission to view the project's builds. |

-> See also [`circleci_workflow_jobs`](workflow_jobs) to list the jobs within a workflow.

## Example Usage

```terraform
# Fetches a workflow by id. Available on both CircleCI Cloud and
# CircleCI Server.
data "circleci_workflow" "this" {
  id = "1e2d3c4b-5a69-7887-9a0b-1c2d3e4f5061"
}

check "workflow_succeeded" {
  assert {
    condition     = contains(["success", "running", "on_hold"], data.circleci_workflow.this.status)
    error_message = "Workflow ${data.circleci_workflow.this.name} is in status ${data.circleci_workflow.this.status}."
  }
}
```

## Schema

### Required

- `id` (String) Unique identifier (UUID) of the workflow.

### Read-Only

- `auto_rerun_number` (Number) Present when this workflow was itself an auto-rerun of a previous workflow: the Nth auto-rerun has `auto_rerun_number` N. Null otherwise.
- `canceled_by` (String) Unique identifier (UUID) of the user who canceled the workflow. Null unless the workflow was canceled.
- `created_at` (String) When the workflow was created, as an RFC 3339 timestamp.
- `errored_by` (String) Unique identifier (UUID) of the user attributed to the workflow erroring. Null unless the workflow errored.
- `max_auto_reruns` (Number) The maximum number of auto-reruns configured for the workflow. Null when auto-rerun is not configured.
- `name` (String) Name of the workflow, as declared in configuration.
- `pipeline_number` (Number) Number of the pipeline run this workflow belongs to.
- `pipeline_run_id` (String) Unique identifier (UUID) of the pipeline run this workflow belongs to. See [`circleci_pipeline_run`](pipeline_run).
- `project_slug` (String) Slug of the project this workflow belongs to.
- `started_by` (String) Unique identifier (UUID) of the user who started the workflow.
- `status` (String) Current status of the workflow: one of `unauthorized`, `error`, `not_run`, `running`, `failing`, `on_hold`, `canceled`, `failed` or `success`.
- `stopped_at` (String) When the workflow stopped, as an RFC 3339 timestamp. Null while the workflow is still running.
- `tag` (String) `setup` when this is a setup workflow. Null otherwise.
