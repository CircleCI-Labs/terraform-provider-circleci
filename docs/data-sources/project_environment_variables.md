# circleci_project_environment_variables (Data Source)

Fetches every environment variable set on a CircleCI project, including variables
created outside Terraform. Pagination is followed internally, so the result covers
every variable rather than a single page. Use
[`circleci_project_environment_variable`](project_environment_variable) to fetch
one by name.

## Availability

| CircleCI Cloud | CircleCI Server |
|---|---|
| yes | yes |

Project environment variables are served by the v2 API, which both deployments
provide.

~> **Values are masked by the API.** CircleCI never discloses an environment
variable's value. It returns four `x` characters followed by the last four
characters of the real value, matching what the web UI displays. Use this data
source to discover *which* variables are set, not what they are set to — a masked
value cannot be fed into another resource.

## Example Usage

```terraform
data "circleci_project_environment_variables" "project" {
  project_slug = "circleci/AbCdEfG/HiJkLmN"
}

output "circleci_environment_variable_names" {
  value = [for variable in data.circleci_project_environment_variables.project.environment_variables : variable.name]
}

# Fail the plan when a variable the pipeline depends on has not been set.
check "required_environment_variables_exist" {
  assert {
    condition = length(setsubtract(
      toset(["DEPLOY_TARGET", "REGISTRY_HOST"]),
      toset([for variable in data.circleci_project_environment_variables.project.environment_variables : variable.name]),
    )) == 0
    error_message = "The project is missing an environment variable the deploy job needs."
  }
}
```

### Nested Schema for `environment_variables`

Read-Only:

- `created_at` (String) Timestamp the variable was created, as the API reported it. Empty for variables created before CircleCI recorded it.
- `name` (String) Name of the environment variable.
- `value` (String, Sensitive) Masked value of the environment variable, as returned by the API. This is never the real value.

## Notes

* `value` is the masked value the API returned, and is marked sensitive so that
  Terraform does not print it. It is never the real value.
* `created_at` is empty for variables created before CircleCI began recording the
  timestamp.
* The API returns the variables sorted by name.
* `environment_variables` is always a list, empty when the project has none, so
  configurations can iterate over it unconditionally.
* `project_slug` must be of the form `vcs-slug/org-name/repo-name`. A malformed
  slug is reported as a configuration error rather than sent as a request that
  would 404.
