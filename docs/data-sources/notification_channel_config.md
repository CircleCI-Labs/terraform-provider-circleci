# circleci_notification_channel_config (Data Source)

Looks up a CircleCI notification channel config by its id.

## Availability

| | |
| --- | --- |
| **CircleCI Cloud** | Yes |
| **CircleCI Server** | No — served by the CircleCI v3 API, which a Server installation does not route to its public API service. Using this with `deployment = "server"` reports an explicit error rather than the confusing HTTP 404 the request would otherwise produce. |
| **API** | `GET /api/v3/notification/channel-configs/{id}` |
| **Organization type** | Any. |
| **Token** | Any valid API token with read access to the organization. |

## Example Usage

```terraform
# Look up a channel config by id, for one this configuration does not manage.
data "circleci_notification_channel_config" "example" {
  id = "22222222-2222-2222-2222-222222222222"
}

output "channel_config_target" {
  value = data.circleci_notification_channel_config.example.target
}
```

## Schema

### Required

- `id` (String) Unique identifier (UUID) of the channel config.

### Read-Only

- `channel_name` (String) The Slack channel name CircleCI resolved for `target`. Populated only for a project-scoped Slack config; null otherwise.
- `channel_type` (String) The delivery channel: `email` or `slack`.
- `is_enabled` (Boolean) Whether this channel is active.
- `org_id` (String) Unique identifier (UUID) of the organization this config is tied to.
- `project_id` (String) Unique identifier (UUID) of the project this config belongs to. Null for a user-scoped config.
- `scope` (String) Whether this config belongs to a user (`user`) or a project (`project`).
- `target` (String) The delivery address: an email address, or a Slack channel ID.
- `user_id` (String) Unique identifier (UUID) of the user this config belongs to. Null for a project-scoped config.
