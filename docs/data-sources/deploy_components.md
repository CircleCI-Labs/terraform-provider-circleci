# circleci_deploy_components (Data Source)

Fetches every CircleCI deploy/release component in an organization, optionally scoped to one project or
filtered by name. Components are declared in a project's `.circleci/config.yml` (the `component` key on a
deploy job) rather than created through the API, so this is read-only.

Pagination is followed internally, so the result covers every matching component rather than one page.

## Availability

| | |
| --- | --- |
| **CircleCI Cloud** | Yes |
| **CircleCI Server** | No — deploy/release tracking (the API) is not deployed on CircleCI Server. Using this data source with `deployment = "server"` reports an explicit error. |
| **API** | `GET /api/v2/deploy/components` |
| **Organization type** | Any. |
| **Token** | Any valid API token. |

-> **Versions are a separate, per-component read.** Use
[`circleci_deploy_component`](deploy_component) to fetch one component by id, including every version
published for it.

## Example Usage

```terraform
# Lists every deploy/release component in the organization.
# Available on CircleCI Cloud only.
data "circleci_deploy_components" "all" {
  org_id = "00000000-0000-0000-0000-000000000000"
}

# Scope the listing to one CircleCI project.
data "circleci_deploy_components" "for_project" {
  org_id     = "00000000-0000-0000-0000-000000000000"
  project_id = "11111111-1111-1111-1111-111111111111"
}

output "circleci_component_names" {
  value = [for c in data.circleci_deploy_components.all.components : c.name]
}
```

## Schema

### Optional

- `name` (String) Component name to filter by. Leave unset to list every component.
- `org_id` (String) The unique identifier (UUID) of the organization to read deploy components from.

This is the same field as the deprecated `organization_id`; set exactly one of the two.
- `organization_id` (String, Deprecated) The unique identifier (UUID) of the organization to read deploy components from.

~> **Deprecated in favour of `org_id`**, which matches CircleCI's own naming. Both work and mean the same thing; set exactly one.
- `project_id` (String) Unique identifier (UUID) of a CircleCI project to filter by. Leave unset to list components across every project in the organization.

### Read-Only

- `components` (Attributes List) The components matching the given filters, sorted by name and project id. (see [below for nested schema](#nestedatt--components))

### Nested Schema for `components`

Read-Only:

- `archived_at` (String) When the component was archived, as an RFC 3339 timestamp. Null when the component is not archived.
- `created_at` (String) When the component was first observed, as an RFC 3339 timestamp.
- `id` (String) Unique identifier (UUID) of the component.
- `labels` (Map of String) Labels attached to the component, as a map of label key to value.
- `name` (String) Name of the component.
- `project_id` (String) Unique identifier (UUID) of the CircleCI project the component is associated with. Null when the component has no associated project.
- `release_count` (Number) Total number of releases recorded for this component.
- `updated_at` (String) When the component was last updated, as an RFC 3339 timestamp.
