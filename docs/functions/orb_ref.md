# function: orb_ref

Builds the `namespace/orb@version` reference that the CircleCI orb version API's `filter[ref]` parameter requires.

Getting this wrong was a real bug in this provider: `filter[ref]` silently resolves nothing unless it is given the fully qualified form — passing a bare version string such as `"1.2.3"` does not fall back to filtering by orb, it just matches no version at all. This function validates each part so a malformed reference (a namespace or orb name containing `/`, `@` or whitespace, or a version that is not a semantic version, a `dev:` label or `volatile`) fails at plan time instead of resolving to nothing at apply time.

## Example Usage

```terraform
# namespace/orb@version — the fully qualified form the orb version API's
# filter[ref] parameter requires. A bare version string such as "1.2.3"
# resolves nothing on its own.
output "qualified_ref" {
  value = provider::circleci::orb_ref("circleci", "node", "1.2.3")
}

output "dev_release_ref" {
  value = provider::circleci::orb_ref("circleci", "node", "dev:my-branch")
}
```

## Arguments

<!-- arguments generated by tfplugindocs -->
1. `namespace` (String) The orb namespace (e.g. `circleci`), with no `/`, `@` or whitespace.
1. `orb` (String) The orb name alone, without its namespace prefix (e.g. `node`), with no `/`, `@` or whitespace.
1. `version` (String) A semantic version such as `"1.2.3"`, a `"dev:<label>"` development release, or `"volatile"`.
